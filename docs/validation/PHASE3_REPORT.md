## Резервные копии и ограничения

База до обновления: `%APPDATA%/TalkCRM Desktop/backups/phase3-20261004/talkcrm-before-0.3.0.sqlite`. Прежний установщик: `release/phase3/TalkCRM Setup 0.2.1.exe`. Обычное отключение сохраняет материалы; явное удаление предусмотрено в отдельной кнопке.

Режим API сверён с OpenAPI и тестовыми контрактами; живого административного ключа нет, поэтому он не объявляется проверенным на реальном аккаунте. Это не блокирует подтверждённый обычный вход.

В исходных записях protocolV2=notAvailable, поэтому импорт задач/решений из реального протокола сравнить нельзя. Интерфейс показывает недоступность. Клиентская классификация и сопоставление с amoCRM принадлежат следующей фазе.

Наблюдённые web-контракты не содержат change feed. Перечень последних 90 дней и readiness перечитываются; HTTP ETag используется при наличии, неизменённые сегменты не пересоздаются. Готовящийся материал перепроверяется при ручном обновлении. Browser storage выделенной Chromium-сессии не получает недоказанных обещаний общего DPAPI-шифрования; API-ключ шифруется через safeStorage.
