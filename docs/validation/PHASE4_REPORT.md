## Ограничения и готовность

Лексические правила не определяют роль участника и не понимают все словоформы, сокращения и произвольные косвенные упоминания. Несколько возможных сделок и встречи без точных признаков требуют ручного выбора. Живой административный API-ключ Толка по-прежнему отсутствует; реально проверен обычный вход сотрудника. Протоколы недоступны в исходном наборе и не выдумываются.

Инфраструктура встречи → клиент → сделка готова для дальнейшего рабочего пространства и шаблонов; любой следующий процесс должен использовать только подтверждённую связь и проверять наличие сделки. В реальном наборе таких связей пока нет. Phase 5 не начата.

Статус итоговой ручной Windows-проверки снятия тестовой связи: ожидается ответ пользователя. Финальный установщик подготовлен; данные источников и установленная рабочая версия сохранены.
