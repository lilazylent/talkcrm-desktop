## Реализованная запись в amoCRM

| Сущность | Операции | Проверено |
| --- | --- | --- |
| Сделка | название, бюджет, этап/воронка (закрытие и возврат — с подтверждением), дополнительные поля | автотесты + фальшивый сервер amoCRM, синтетический предпросмотр |
| Контакт | имя, все телефоны/почты с типами, дополнительные поля | то же |
| Компания | название, дополнительные поля | то же (в реальном аккаунте компаний 0) |
| Задача | создание, текст, перенос срока, тип, выполнение с результатом | то же |
| Примечание | создание common; изменение только созданных в TalkCRM | то же |

Поддерживаемые типы полей: text, textarea, numeric, checkbox, select, radiobutton, multiselect, date, date_time, birthday, url, multitext. Остальные (в реальном аккаунте: file — 3, tracking_data — 21) только для чтения. Возврат выполненной задачи в работу не включён: безопасность снятия `is_completed` не подтверждена.

## Известные ограничения

- Запись в реальный amoCRM не проверялась (решение пользователя); запись через cookie-сессию сотрудника не подтверждена.
- Возврат выполненной задачи не поддерживается; удаление записей amoCRM не поддерживается.
- Ответственный задачи — всегда текущий менеджер; каталог пользователей amoCRM не запрашивается, ответственные показываются как «Пользователь #ID».
- В кэше только сделки текущего менеджера; редактировать можно только их.
- Нет фонового обновления и вебхуков: обновление вручную, после записи и при открытии устаревшей карточки.
- Названия групп полей зависят от доступности `/custom_fields/groups`.
