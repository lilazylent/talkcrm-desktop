# Дизайн-система TalkCRM

Редизайн 0.4.1. Весь интерфейс собирается из токенов `src/styles/tokens.css` и примитивов `src/components/ui.tsx`. Новых цветов, размеров и отступов в коде страниц не задаём — только через токены.

## Принципы

- **Одна главная задача на экране.** Главная ведёт к разбору встреч («Разобрать встречи»), карточка встречи — к подтверждению связи с CRM (правая панель всегда на виду).
- **Цифровой характер без шума.** Тёмное боковое меню, градиент бренда только в акцентах (логотип, активный пункт, главная кнопка, индикатор вкладки), моноширинный шрифт для дат, сумм, ID и меток.
- **Читаемость.** Основной текст 15px, вторичный не меньше 13px, 12px — только моноширинные метки капсом.
- **Ровная сетка.** Шаг 4/8px, отступ между блоками 24px, ширина контента до 1360px, единые высоты контролов 32/40/48px.

## Токены

| Группа | Значения |
| --- | --- |
| Шрифты | Onest Variable (интерфейс), JetBrains Mono Variable (данные). Встроены в сборку, работают офлайн и под CSP |
| Кегли | 12 / 13 / 14 / 15 (база) / 16 / 17 / 20 / 28 / 34 |
| Отступы | `--s-1`…`--s-10` = 4, 8, 12, 16, 20, 24, 32, 40, 48, 64 |
| Скругления | 6 (чипы), 8, 10 (контролы), 14 (карточки), 20 (герой, модальные окна) |
| Цвета | `--bg`, `--surface(-2,-3)`, `--line(-soft,-strong,-input)`, `--text(-2,-3)`, `--accent*`, `--success/warning/danger/info/violet` + `-soft`, `-text` |
| Тени | `--shadow-xs/sm/md/lg` |
| Движение | 120 / 200 / 320 мс, `cubic-bezier(.2,.8,.2,1)`; уважается `prefers-reduced-motion` |

Темы: светлая, тёмная и «как в системе» (переключатель в меню и в «Настройки → Оформление», выбор хранится локально). Рамка окна Electron (`titleBarOverlay`) перекрашивается вместе с темой через IPC `window:theme`.

Контраст проверен расчётом по WCAG 2.1 AA: текст ≥ 4.5:1 в обеих темах, белый текст на кнопках ≥ 5:1, границы полей ввода ~3:1.

## Компоненты (`ui.tsx`)

`PageHeader`, `BackLink`, `Section` (панель с иконкой и действием), `EmptyState`, `SearchField`, `Select`, `Badge` (тона neutral/accent/success/warning/danger/info/violet), `StatusBadge`, `StageBadge` (тон по смыслу этапа), `Avatar` (инициалы, цвет по хэшу имени), `Modal` (Escape, удержание фокуса, возврат фокуса), `Notice`, `Segmented` (счётчики скрыты от экранного диктора), `Facts`.

CSS-классы: кнопки `.btn` + `-primary/-glow/-ghost/-danger/-danger-soft`, `-sm/-lg/-block`; `.icon-btn`, `.link-btn`; таблица `.table/.t-head/.t-row` с сеткой страницы; списки `.list/.list-row`; `.tabs`, `.kv`, `.facts`, `.toast`, `.progress-line`, `.live-dot`.

## Каркас

- `Sidebar` — разделы «Работа» (Главная, Встречи, Клиенты, Сделки, Задачи) и «Система», счётчики (встречи на разбор, активные сделки, просроченные задачи), статус источников, профиль, тема, сворачивание до иконок.
- `Topbar` — быстрый поиск (Ctrl+K), источник данных, время обновления, «Обновить», полоса прогресса синхронизации. Служит областью перетаскивания окна.
- `CommandPalette` — поиск по разделам, встречам, клиентам и сделкам, управление стрелками/Enter/Esc.

## Визуальная проверка

`npm run dev -- --port 5174` и открыть `http://127.0.0.1:5174/` (демо). Встречи Толка с кандидатами: `?preview=matching` — нужен синтетический `public/matching-preview.json` (не коммитится).
