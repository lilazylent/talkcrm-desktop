# amoCRM: переписки в TalkCRM

Краткая памятка для пользователя и разработчика. Архитектура — [MESSAGING_ARCHITECTURE.md](MESSAGING_ARCHITECTURE.md).

- **Источник:** официальный `GET /api/v4/talks` (документация amoCRM «Беседы»), доступный всем пользователям аккаунта; данные зависят от прав на контакт.
- **Что видно в TalkCRM:** какие переписки есть у клиента, в каком канале, в работе ли, прочитаны ли, с какой сделкой связаны, когда обновлялись.
- **Что делается в amoCRM:** чтение сообщений и ответ клиенту — кнопка «Открыть в amoCRM» открывает нужную карточку.
- **Официальный Chats API** работает только для собственного канала интеграции; существующие каналы сторонних виджетов TalkCRM не использует от их имени.
- **Обновление:** при синхронизации amoCRM и при открытии карточки клиента (если данные устарели); вручную — «Обновить».
- **Без соединения:** список переписок из кэша остаётся видимым; открыть amoCRM можно после восстановления связи.
- **Фактические каналы аккаунта** фиксируются в `docs/validation/PHASE6_REPORT.md` только как типы каналов и количества.
