# Проверка интерфейса Контур.Толка

В открытом пользователем desktop приложении «Толк» проверены календарь, Артефакты → Записи и одна карточка записи. Пространство: `https://samosale-app.ktalk.ru/`. Дата фиксации: 04.10.2026.

Наблюдения:
- Список доступен по `/content/artifacts/recordings`; карточки имеют стабильные ссылки `/recordings/<id>`, названия, даты, длительность и участников.
- Карточка доступна сотруднику. На ней есть пересказ с временными метками и вкладка «Транскрипция», а также заметки, участники и скачивание.
- Название одной встречи содержит номер, похожий на номер CRM-сделки. Это лишь кандидат для сопоставления, требуется проверка в amoCRM.

Вход и настройки безопасности не менялись, запись не воспроизводилась и не скачивалась, сообщения не отправлялись. Не проверены: весь архив, полнота транскрипции, доступность API/экспорта, автоматическое чтение и новые записи. Локальный адаптер ещё не реализован. Не переносить cookies или секреты установленного приложения.
