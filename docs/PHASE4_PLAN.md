# Phase 4 — план и проверяемый контракт

База: 0.3.0. Результат: 0.4.0, локальная связь логической встречи с клиентом и необязательной сделкой. Авторизация и сетевые адаптеры остаются существующими. Анализ работает только по текущему локальному CRM-кэшу менеджера.

## Этапы

1. Нормализация, индекс известных сущностей, детерминированные предложения и тесты сигналов/противоречий.
2. Миграция 005: связь, предложения, доказательства и история; защита подтверждения при обновлении и объединении записей.
3. Ограниченный IPC, выбор/подтверждение/смена/снятие связи, переход к фрагменту транскрипции.
4. Фильтры встреч, пакетный поиск, встречи в клиентском пространстве и контексте сделки.
5. Полный набор проверок, синтетические состояния интерфейса, предложения для реальных трёх встреч без подтверждения, сборка и обновление установленной версии с резервной копией.

## Сценарии приёмки

- Полный email/телефон дают сильный сигнал; часть номера/email не совпадает.
- ФИО с другим порядком слов сопоставляется; одно распространённое имя не даёт уверенности; инициалы/опечатки остаются слабыми.
- ООО/ИП/АО/ПАО, кавычки, ё/е нормализуются; родовые названия не дают высокой уверенности.
- Название, все пересказы и сегменты дают объяснения с исходными ID; повторение причины не увеличивает вес.
- Несколько активных сделок требуют выбора, закрытые не получают бонус активной сделки; противоречащие сильные сигналы требуют проверки.
- Только подтверждение пользователем меняет авторитетную связь. Повторный поиск/синхронизация сохраняют её; новые противоречия выводят предупреждение.
- Смена и снятие связи обратимы через историю, источники не удаляются. После перезапуска и объединения записей связь сохраняется.
- Обновление 0.3.0 сохраняет amoCRM, 3 встречи/4 записи/891 сегмент/4 пересказа, настройки и метаданные сессий.

## Начальная модель весов

Email/телефон 90; компания в названии 65; сделка в названии 75; компания в пересказе 35/транскрипции 30; сделка в пересказе 65/транскрипции 55; полное имя участника 40, инициалы 20, ограниченная опечатка 15; имя в тексте 20; активная сделка 3, единственная активная 6. Для каждой смысловой причины учитывается максимальный вес один раз. Итог 0–100; высокая от 80 при сильном сигнале, средняя от 40. Противоречие ограничивает результат 39, неоднозначность сделок — 69 без прямого упоминания сделки. Точные итоговые правила будут задокументированы вместе с реализацией.

Статус: реализация, 126 автоматических тестов, миграция, сборка и обновление установленной версии проверены. Итоговая Windows-проверка последнего клика снятия синтетической связи ожидает ответа пользователя по правилу навыка computer-use. Реальных подтверждений 0. Phase 5 не входит в объём.
